## 🆘 Troubleshooting

### If sitemaps not showing in Google Search Console:
1. Verify sitemap is accessible: Visit `https://www.meenkodi.com/sitemap-index.xml`
2. Check robots.txt: Visit `https://www.meenkodi.com/robots.txt`
3. Validate XML: Use https://www.xml-sitemaps.com/validate-xml-sitemap.html
4. Re-submit in Search Console

### If pages not getting indexed:
1. Use URL Inspection tool in Search Console
2. Check for crawl blocks in robots.txt
3. Ensure pages have proper content (not thin content)
4. Request indexing manually for important pages

### If seeing errors:
1. Check MongoDB connection is working
2. Verify all content has proper slugs
3. Ensure images have valid URLs
4. Run the generator script again
